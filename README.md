# Velora Drive — Premium Car Rental & Chauffeur Service (Dhaka)

A high-converting, modern luxury car rental and chauffeur service landing page designed for the Dhaka, Bangladesh market.

---

## 🚀 Live Files & Deliverables

- **`index.html`**: Complete high-fidelity landing page with full-screen looping video background hero, floating full-glass navbar, booking engine bar, infinite editorial auto-scrolling fleet carousel, electric charging hub simulator, FAQ accordions, and 1440px desktop / 390px mobile responsiveness.
- **`hero.mp4`**: High-definition background video for the cinematic hero section.
- **`hero-poster.jpg`**: Fast-loading fallback poster for the video hero.
- **`styleguide.html`**: Design System & Style Guide specifying typography scales, glass UI tokens, radii, and color palette.
- **`behance-case-study.html`**: Complete presentation case study framework.

---

## 🎨 Visual System & Brand Tokens

| Token | Value | Role |
| :--- | :--- | :--- |
| **Page Canvas** | `#FFFFFF` / `#F5F6F8` | Clean, architectural modern canvas |
| **Hero Background** | `#000000` | Cinematic deep black video hero |
| **Ink Black** | `#0E0F12` | Headings, primary pill buttons, dark contrast cards |
| **Secondary Text** | `#5C6068` | Body copy, specs, and labels |
| **Electric Blue** | `#2F5BFF` | Signature electric accent (dots, active states, focus rings) |
| **Glass UI** | `rgba(255,255,255,0.10)` | Floating pill navbar, booking bar, floating badges (blur: 22px) |

### Typography
- **Headings & Body**: `Manrope` (tight tracking, modern sans-serif)
- **Serif Accent**: `Instrument Serif` (italic accent word in key headlines, e.g., *"Arrive in style."*)

## 💻 How to Run Locally

You can open `index.html` directly in any web browser, or run the included PowerShell web server:

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1 -Port 5500
```
Then visit [http://localhost:5500/](http://localhost:5500/).
